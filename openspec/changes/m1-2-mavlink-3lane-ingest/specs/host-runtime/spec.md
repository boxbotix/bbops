## MODIFIED Requirements

### Requirement: Embedded NATS JetStream and SemEngine SKG pipeline lifecycle
The `bbops` host runtime SHALL start an embedded NATS server with JetStream enabled (unless an external `-nats-url` is configured), ensure the `ENTITY` stream on `entity.>` with explicit finite `max_age`, `max_bytes`, and `discard: "old"` retention, enforce `ENTITY_STATES` KV single-revision compaction (`History: 1`, `RetentionNoLifecycle`), compose the external MAVLink v2 UDP ingest adapter alongside `processor/graph-ingest` (`WriteOwnerOnly`), `processor/graph-index` (`coalesce_ms: 500`), `processor/graph-query`, and `processor/graph-lexical` (with CLI and ephemeral loopback UDP port override support so concurrent host instances never collide on `:14550`), gate readiness on startup completion so `graph-ingest`, query responders, and enabled ingest listeners are active before ready probes succeed, and shut down all services, UDP/WebSocket listeners, and embedded NATS cleanly on context cancellation.

#### Scenario: Readiness succeeds only after embedded NATS, MAVLink UDP ingest, and graph-ingest pipeline boot
- **WHEN** `bbops` boots in-process on ephemeral loopback TCP/UDP ports (`1024..65535`) with a temporary JetStream data directory
- **THEN** readiness and health probes report ready (`200`), `ENTITY` stream carries finite `max_age`/`max_bytes` with `discard: "old"`, `ENTITY_STATES` KV is configured with `History: 1`, the resolved MAVLink UDP endpoint is bound without colliding across concurrent instances, and canceling the host context stops `ServiceManager`, the UDP ingest adapter, and embedded NATS cleanly

## Goals / Non-Goals
- **Goals:** Keep vehicle identity, `ControlAuthority`, `ARMED`/`DISARMED`, and freshness visible on selection without whole-page scrolling at `1024×768` and `1440×900` (`100%` zoom); keep `.invariant-topbar` safety status visible during long roster/detail scrolling without obscuring `:focus-visible` controls; keep fleet switching reachable without requiring permanent space for both `Roster` and `FleetFilmstrip` at compact widths; preserve `#40`/`#41` selection, workspace drafts/queries, and keyboard focus return across panel open/close/resize with a clear route back to `TacticalCanvas`; prevent overlap/clipping and horizontal page scrolling across long names, multi-faults, empty states, growing rosters, and `200%` browser zoom.
- **Non-Goals:** Phone operating UI, map-engine replacement (`#16`), wholesale visual redesign, or `M3.1` command actuation (`#11`).

## Risks / Trade-offs
- **Existing E2E geometry & focus assumptions:** `cop-workspace.e2e.ts:287-304` resizes `1024×768` -> `1440×900` before running canvas hit-tests (`410-423`), and `1066-1196` runs at default `1440×900` (`playwright.config.ts:21`) expecting `[data-testid="cop-roster"]` and `[data-testid="cop-solo-rail"]` visible. Defaulting both rails open at `>= 1200px` (`1440×900`) keeps all existing E2E assertions green while dedicated `#42` E2E tests exercise `1024×768`, `1440×900`, `200%` zoom, long names, multi-faults, empty data, and panel toggles.
- **Sticky header vs. `200%` zoom height (`384px` CSS height at `1024×768`):** Wrapping `.invariant-topbar` into 3+ tall rows at `512×384` CSS px could consume excessive vertical height if sticky unconditionally; capping/compacting topbar wrapping and disabling `position: sticky` (or pinning only the status row) at ultra-short CSS heights (`< 420px`) prevents content starvation at `200%` zoom while keeping sticky safety status across desktop scrolling (`768px` / `900px`).

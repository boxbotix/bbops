## Goals / Non-Goals
- **Goals:** Pin per-`sysid` TX peer endpoints safely; emit `1 Hz` GCS `#0 HEARTBEAT` while active; enforce at-most-once `10–30 Hz` `#84` velocity teleop (`type_mask = 0x07C7`, finite floats, `< 250 ms` server deadman, `mesh-supervisory` & authority/link-loss gates, zero KV/JetStream persistence); implement ADR-111 Decision 3 non-retrying `#76 COMMAND_LONG` -> `#77 COMMAND_ACK` (`commit_unknown` on timeout reconciled via `HEARTBEAT`); deliver `ControlPanel.svelte` with `sitl-local` fault/current lab (`MAV_CMD_USER_1`) and `< 2 ms`-edge UI/server release + CAS preemption on `direct-crsf-override` / `mcu-failsafe`; preserve `#39`/`#41`/`#43` invariants.

## Risks / Trade-offs
- **ACK loss vs. late state convergence (`ADR-111` Decision 3):** Dropping `#77 COMMAND_ACK` transitions the command to `commit_unknown` after timeout (`1.5 s` default, `3.5 s` on `mesh-supervisory`) with **zero** automatic re-send; subsequent `#0 HEARTBEAT` authority/armed/mode edges reconcile observed vehicle state without masking the `commit_unknown` audit trail.
- **Browser timer throttling on background tabs:** `visibilitychange` / `window.blur` immediately disengages UI teleop and sends a zero/stop release, backed up independently by the `< 250 ms` server-side lease deadline before `bbnav`'s `300 ms` `CommandMux` deadman clamps.
